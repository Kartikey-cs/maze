### Prerequisites

## Raylib
 Documentation: https://www.raylib.com/
 Cmd: pacman -S mingw-w64-ucrt-x86_64-raylib
Used for:

- Window creation
- Graphics rendering
- Input handling
- Audio
- Textures
- Animations

## Raygui
Raygui.h(https://github.com/raysan5/raygui)
Used for:

- Textboxes
- Buttons
- Sliders
- Checkboxes
- GUI widgets
